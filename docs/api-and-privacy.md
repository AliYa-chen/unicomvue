# 隐私 / Cookie / Token 说明

本说明适用于余量面板提供的账号查询服务及浏览器前端。

本说明面向服务用户，介绍账号登录、查询与展示过程中使用的公开接口，以及浏览器端的数据处理方式。服务端技术与安全配置按内部规范管理。

## 服务说明与免责声明

- 本服务独立提供联通账号信息查询与展示，不代表运营商官方业务办理渠道，也不会变更用户的账号、套餐或业务状态。
- 手机号、短信验证码和 Token 仅用于完成账号登录与信息查询；Token 仅在用户主动操作时用于复制，不用于与本服务无关的用途。
- 本服务仅在完成用户发起的登录与查询过程中处理必要的手机号、短信验证码和 Token；服务端不会持久化保存上述凭证，浏览器端的保存范围见下文“localStorage 与 Cookie”。
- 用户应仅查询本人或已获合法授权的账号，并对提交的手机号、验证码、Token、查询授权及使用行为负责。
- 查询结果依据接口实时返回的数据整理展示；套餐权益、计费结果、业务生效状态及账号记录，以中国联通官方系统和正式账单为准。
- 用户应妥善保管账号凭证。因主动共享凭证、越权使用或违反适用规则产生的责任，由相关责任方承担。
- 为保障服务安全、稳定与公平使用，服务方可对批量请求、接口滥用、越权查询、商业化转售及其他异常使用采取访问限制。
- 使用本服务即表示用户已阅读并接受本说明。

## 数据流

1. 浏览器前端通过 HTTPS 向项目 API 网关发送登录或查询请求。
2. 服务 API 网关完成业务所需的运营商信息查询。
3. 需要安全验证时，浏览器按需加载腾讯云验证码组件，并将验证结果提交给项目 API 网关。
4. 应用运行期间，浏览器直接查询当前公网 IP、地区、运营商和接入类型，并向网络连通性地址发送不携带凭证的探测请求，用于展示网络信息和 HTTP 往返延迟。
5. 仅在用户主动开始测速后，浏览器直接向所选测速文件地址持续发起下载请求；该流程不经过项目 API 网关。

## 浏览器直接调用的接口

默认基础地址为 `https://networkapi.2t.hk`。以下接口均使用 `POST`，请求正文为 JSON 序列化数据，当前请求头为 `Content-Type: text/plain;charset=UTF-8`，响应应为 JSON。单次请求默认在 20 秒后超时，并支持在切换账号、关闭登录窗口或销毁页面时主动取消。

### 登录接口

| 路径 | 用途 | 前端提交的公开字段 | 前端读取的响应 |
| --- | --- | --- | --- |
| `/gettoken/?action=send` | 请求短信验证码，必要时触发安全验证 | 手机号、浏览器登录标识、设备标识、可选的验证结果令牌 | 状态、提示信息、验证上下文 |
| `/gettoken/?action=validate` | 校验腾讯云验证码结果 | Captcha Ticket、随机串、验证上下文、手机号、浏览器登录标识、设备标识 | 状态、提示信息、后续短信请求所需的结果令牌 |
| `/gettoken/?action=login` | 使用手机号和短信验证码登录 | 手机号、短信验证码、浏览器登录标识、设备标识 | 状态、提示信息、`ecs_token`、可选的 `onlin_token` |

浏览器登录标识和设备标识由前端生成并保存在当前站点的 `localStorage`，用于在登录流程中保持设备身份一致。

### 查询接口

| 路径 | 用途 | 前端提交的公开字段 | 前端读取的响应 |
| --- | --- | --- | --- |
| `/ocs_proxy/` | 查询套餐及资源余量 | `ecs_token` | 套餐名称、流量、语音、短信及资源明细 |
| `/basicdata_proxy/` | 查询基础网络信息 | `ecs_token` | 脱敏号码、签约速率、LTE 状态 |
| `/qci_proxy/` | 查询 QCI 与限速状态 | `ecs_token` | QCI、限速服务状态、可用最高速率 |

查询接口使用请求正文中的 `ecs_token` 识别登录状态。

### 网络测速接口（第三方）

测速页以跨域 `GET` 请求读取所选文件的响应流；文件读取结束后会立即重新请求，并按所选线程数并行持续下载。内置清单包含 npmmirror、腾讯云 npm、阿里云 OSS、华为云 CDN、国内静态 CDN，以及 Cachefly、Cloudflare Speed、Steam Akamai 和 Steam Cloudflare 全球节点，也可由用户保存自定义 HTTP 或 HTTPS 文件地址。第三方节点的可用性、跨域策略和传输协议可能随服务商与当前网络环境变化。请求不附带 Cookie 或账号凭证，并使用 `no-referrer`；点击停止、关闭页面、切换节点或减少线程数时会取消对应请求。测速没有固定流量上限，页面统计与运营商实际计费流量可能因协议开销等因素略有差异。

应用运行期间还会直接调用以下第三方接口：

| 地址 | 用途 | 前端处理 |
| --- | --- | --- |
| `https://app.netart.cn/network-panel/ip.ajax` | 获取当前公网 IP 或指定出口 IP 的地区、运营商和接入类型 | 使用不携带 Cookie 的跨域 `GET`；公网 IP 仅保存在当前页面运行内存中，用户悬浮、聚焦或点击网络状态条时显示，不写入本地存储 |
| `https://cp.cloudflare.com/cdn-cgi/trace` | 识别国际链路出口；国际线路下同时作为延迟探测地址 | 使用不携带 Cookie 的跨域 `GET`；仅在返回的出口归属为非中国地区时标记“国际线路” |
| `https://connectivitycheck.platform.hicloud.com/generate_204` | 测量国内线路到连通性探测地址的 HTTP 往返耗时 | 使用 `HEAD`、`no-cors`、`no-store` 顺序采样并取最近三次中位数；该数值不是 ICMP Ping |

网络状态在应用运行期间持续轮询：出口线路识别和延迟探测的目标周期均为约 500 毫秒；请求耗时超过该周期时不会叠加新请求，而是在当前请求结束后立即继续。出口 IP 或归属地区发生变化时会立即重新查询地区、运营商和接入类型，未变化时也会约每 60 秒刷新一次。离线或组件销毁时会取消仍在进行的请求，恢复联网后自动继续。接口失败只会使网络状态条显示占位或重试入口，不影响持续下载测速。

所选文件、IP 信息及延迟探测服务的服务方会看到访问请求的公网 IP 等常规连接信息；自定义地址的安全性与隐私政策由用户自行确认。测速请求不包含手机号、验证码、`ecs_token`、`onlin_token` 或账号资料。结果仅代表当前设备到对应服务的链路，不能代替运营商官方测速或套餐签约速率。

## 第三方前端依赖

当短信接口要求安全验证时，前端按需加载：

- `GET https://turing.captcha.qcloud.com/TJCaptcha.js`

腾讯云验证码组件会在浏览器中发起完成验证所需的网络请求。组件返回的 Captcha Ticket 和随机串仅用于完成当次安全验证，并提交到 `/gettoken/?action=validate`。

## 服务端业务能力

服务端向前端提供以下业务能力：

- 手机号登录与 Token 获取
- 短信验证码发送
- 腾讯云验证码结果校验
- 套餐、流量、语音及短信资源查询
- 基础网络信息与签约速率查询
- QCI 与限速服务状态查询

## 登录与查询流程

1. 用户输入手机号后，前端请求发送短信验证码。
2. 如果接口要求安全验证，前端加载腾讯云验证码；验证通过后再次请求发送短信。
3. 用户提交短信验证码，登录接口返回前端查询所需的 Token。
4. 直接输入 `ecs_token` 登录会跳过短信登录流程，首次刷新时才发送查询请求。
5. 前端先查询套餐余量，再并行查询基础速率与 QCI。
6. 自动刷新默认每 30 秒执行一次，可由用户暂停或手动触发。

`onlin_token` 不会发送给三个查询接口。用户点击复制后，完整 `onlin_token` 会写入系统剪贴板；长按复制则会把完整 `ecs_token` 写入系统剪贴板。

## localStorage 与 Cookie

前端可能在当前站点的 `localStorage` 中保存以下信息：

- `ecs_token` 与可选的 `onlin_token`
- 多账号列表、当前账号标识和套餐名称
- 手机号或脱敏号码
- 最近使用的手机号
- 浏览器登录标识与设备标识
- 主题偏好
- 是否保存账号、自动刷新与主题强调色偏好
- 测速所选地址、线程数及用户保存的自定义地址清单

这些数据保存在当前站点的浏览器本地存储中，并受浏览器同源机制管理。请仅在可信设备上保存账号，并妥善管理浏览器扩展和设备访问权限。

设置页面中可关闭“在当前浏览器保存账号”。关闭时会立即删除本地账号列表、当前账号标识、旧版 `ecs_token` 缓存和最近手机号；当前页面中的账号仅保留到刷新或关闭页面，不再写入本地存储。再次开启时会保存当前内存中的账号。浏览器登录标识和设备标识仍用于短信登录流程，并不属于账号保存开关的清除范围。

本页面的业务功能不依赖第三方 Cookie；前端不主动读写 Cookie，也不会显式附带跨域 Cookie。

测速结果只保留在当前页面内，不写入 `localStorage`。切换到余量页时测速仍会在后台继续，只有手动停止或关闭页面才会结束；所选地址、线程数和自定义地址清单会保存在 `localStorage`，便于下次恢复设置。

从账号菜单移除账号时，前端会删除该账号在本地保存的 Token；如果仍有其他账号，它们会继续保留。最近手机号、设备标识等辅助数据可能仍在 `localStorage` 中，需要彻底清除时请删除该站点的浏览器存储。

## 剪贴板与截图导出

- 用户主动复制 Token 时，完整 Token 会写入系统剪贴板。剪贴板历史、系统同步服务、浏览器扩展或其他应用可能读取或保留这份内容。
- “截图分享”在浏览器本地生成当前面板图片，图片可能包含脱敏号码、套餐、余量、签约速率和 QCI 等页面信息。前端不会上传该截图。
- 浏览器支持图片剪贴板时，截图会写入系统剪贴板；不支持或写入失败时，前端会改为下载 PNG 文件。已下载文件会保留在用户选择的保存位置或浏览器默认下载目录中。
- 从账号菜单移除账号只会清理应用管理的本地账号状态，不会清除系统剪贴板、剪贴板历史或已经下载的截图。请在共享设备上手动清理这些副本。

## 安全建议

- 只在可信域名和可信设备上输入手机号、验证码或 Token。
- 不要在 Issue、日志、截图或文档中提交真实手机号、验证码、Captcha Ticket、`ecs_token`、`onlin_token` 或 Cookie。
- 自建站点应强制使用 HTTPS，并配置严格的内容安全策略和访问控制。
- 自定义域名需要满足 API 网关的跨域策略；静态部署本身不会自动获得调用权限。
- 发现 Token 泄露时，应立即移除本地账号并通过运营商渠道使相关登录状态失效。
